## İlk bağlantı testi

`nuvio-tek-kart-test.json` yalnızca Aksiyon kapağıyla görsel bağlantısının Nuvio'da çalışmasını denemek içindir. Ayrı bir test koleksiyonu ekler. Henüz tamamlanmış 68 kartlık paket değildir. Bu test kartında hareketli odak görseli ve üst logo kullanılmaz.
