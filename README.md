# Nuvio Türkçe koleksiyon görselleri

Son dosya: [nuvio-koleksiyonlar-Turkce-Tam.json](nuvio-koleksiyonlar-Turkce-Tam.json).

66 kartın 198 Türkçe kapak, odak ve başlık görseli tamamlandı. Son 13 görsel klasik grafik düzenleme yöntemiyle hazırlandı. Yazı tipleri mevcut tasarıma yakın seçildi; özgün fontların birebir eşleşmesi garanti edilmez.

Görseller assets/tr-webp altında kayıpsız WebP biçimindedir. PNG sürümleriyle piksel ölçüleri ve RGBA pikselleri karşılaştırılarak doğrulandı. Eski önizleme bağlantıları korunur.

Yayın Platformları ilk sıradadır. Türler bölümünden Anime ve Kore Dizileri; Uyarlandığı Kaynaklar bölümünden Anime & Manga ve Board Games kaldırıldı.

Orijinal görsel kaynakları: https://art.kaptain.stream/ ve https://github.com/luckynumb3rs/stremio-perfect-setup.
